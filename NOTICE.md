# Upstream provenance

`spagcn-modern` is an independently maintained fork of
[jianhuupenn/SpaGCN](https://github.com/jianhuupenn/SpaGCN).

The maintenance line was created from upstream commit
`dc7a1c26ea0fdf4dfe7064adc7699be141b4871f`. The original authors retain
copyright in their work. Changes made in this fork are distributed under the
same MIT license found in [`LICENSE`](LICENSE).

The distribution name is intentionally different from `SpaGCN`. The Python
import package remains `SpaGCN` for API compatibility.
